# Planity

Planity is a student organizer web app built on ASP.NET MVC. It helps students manage subjects, tasks, grades, and group work in one place.

## Features

- Authentication with roles: `Admin`, `TeamLeader`, `Student`
- Subject tracking with semester/year, credits, schedule, and completion status
- Task management with priorities, status, repeat rules, subtasks, and attachments
- Group collaboration with team leaders and shared tasks
- Grade tracking per subject
- Dashboard and progress views for quick insights
- Admin user management (role switching and user cleanup)

## Tech Stack

- ASP.NET MVC 5, .NET Framework 4.7.2
- Entity Framework 6 + ASP.NET Identity
- SQL Server LocalDB
- Bootstrap, jQuery, DataTables
